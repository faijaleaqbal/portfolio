# Md Faijal Eaqbal — Developer Portfolio

Welcome to the personal developer portfolio repository of **Md Faijal Eaqbal**, a BCA student at Malda College (under Gour Banga University).

## 🚀 Features & Sections
- **Hero & About**: Short intro, educational background, profile highlights.
- **Skills Matrix**: Categorized tech stack & proficiency.
- **Project Showcase**: Featuring GitHub repositories (`Pixel-Assistor`, `malda-portal`, `malda-college-notification-bot`, `Crypto_adss_bot`).
- **Contact & Socials**: Direct form & profile links to GitHub ([@faijaleaqbal](https://github.com/faijaleaqbal)).
- **Interactivity**: Theme toggle (Dark/Light mode), responsive navigation, smooth scrolling.

## 🛠️ Tech Stack
- HTML5, CSS3 (Modern Flexbox/Grid, Glassmorphism, CSS Variables)
- Vanilla JavaScript (IntersectionObserver, DOM Manipulation)
- Google Fonts (Inter, Outfit) & FontAwesome Icons
